# 너의 교수님은?

전공과 진로의 갈림길에서, 교수님을 **찾고 · 만들고 · 잇는** 모바일 우선 프로토타입입니다. 공식 근거로 관련 교수를 찾고(찾다), 전공을 확장한 아이디어를 만들고(만들다), 첫 대화부터 다음 만남까지 이어줍니다(잇다).

기준 문서는 `너의_교수님은_핵심3기능_기능명세_V2_2026-07-29`이며, 브랜드 자산은 V3 패키지에서 `public/brand/nyp-v03/`로 옮겨 `lib/brand-assets.ts`에서 경로를 관리합니다.

## 실행

```bash
npm install
```

루트에 `.env.local`을 만들고 서버 전용 키를 설정합니다.

```bash
OPENAI_API_KEY=your_key_here
OPENAI_MODEL=gpt-5-mini
```

```bash
npm run dev
```

기본 개발 주소는 `http://localhost:3000`입니다.

## 핵심 3기능 MVP

`http://localhost:3000/`에서 `찾다 · 만들다 · 잇다` 세 기능을 같은 무게로 확인할 수 있습니다.

1. 학교는 선택 입력하고, 보편 전공 계열과 학과·전공을 검색하거나 직접 입력
2. 대학생 공통 관심 분야를 최대 3개까지 선택하거나 직접 추가
3. 자유 브레인스토밍, 학과 × AI 트렌드, 전공 융합 중 하나를 선택
4. AI가 한 번에 한 질문을 제시하고 사용자가 확인한 맥락을 누적
5. 숫자 점수 없이 연구질문·데이터·방법·범위·확인할 점을 같은 스키마로 비교
6. 후보를 선택하면 단국대학교 공식 데이터 안에서 주제·방법·확장 관점의 교수 3명을 서로 다른 역할로 연결
7. `/professors/[id]`에서 공식 연구분야·논문 상태·근거 ID 확인
8. `/quest`에서 논문 한입, 첫마디 랜덤박스, 침묵 구조대, 메일 초안, 다음 만남 씨앗 사용
9. `/paper/reader?mode=bite`에서 논문 텍스트를 문제·방법·결과·한계·질문 카드로 정리
10. `/mentor-loop`에서 면담 피드백, 연구안 수정 전후, 7일 행동과 감사·후속 이메일을 저장

학교를 입력하지 않거나 다른 학교를 입력해도 전공 아이디어 만들기는 이용할 수 있습니다. 교수 연결은 데이터 범위를 오해하지 않도록 사용자가 단국대학교를 확인한 경우에만 실행합니다. `/professors`의 필수 입력은 학교 확인·도움 목적·전공·관심 분야 1~3개이고, 구체 연구주제·진로 목표·만남 상황·추가 맥락은 선택입니다.

공식 교수 사진 참조 623건은 현재 모두 표시 허가가 확인되지 않은 참고 전용 상태입니다. 앱은 승인 장부에 교수 ID·이름·공식 출처·로컬 이미지가 함께 등록된 경우에만 실제 사진을 사용하며, 그 전에는 역할별 브랜드 교수 일러스트를 표시합니다.

공식 프로필에 연구분야나 논문 목록이 없으면 추정해서 채우지 않습니다. `공식 프로필 미기재`, `프로필 접근 불가`, `파싱 실패`, `robots 차단`을 별도 상태로 기록합니다. 서비스의 공식 교수 목록에 포함된 모든 논문 서지는 그대로 보여주고, 논문을 선택했을 때 DOI를 우선하며 제목·발행일을 보조 기준으로 OpenAlex와 Crossref의 공개 초록을 조회합니다. 정확히 일치하지 않으면 자동 입력하지 않고, 같은 교수의 다른 공식 목록 제목과 이어지는 공개 논문이 확인된 경우에만 제목·연도·DOI를 후보로 보여준 뒤 학생이 확인해야 불러옵니다. 조회 결과는 서버에서 최대 30일간 재사용합니다.

현재 런타임 데이터는 단국대 공식 디렉터리 115개 학과·전공을 시도한 정규화 결과 1,051명입니다. 학과 소속 결과가 공식 중앙 교원검색에도 없는 3개 전공은 `PARTIAL` 범위 공백으로 표시합니다. 교수 선택 과정에는 점수·순위 필드가 없습니다. `OFFICIAL_EVIDENCE_RULES_V3`가 주제·방법·확장 관점별 공식 근거를 확인하고, 같은 조건에서는 안정적인 교수 ID 순서로 결과를 재현합니다. 특정 역할의 직접 근거가 부족하면 해당 카드를 `LIMITED`로 표시하고 무엇을 직접 확인해야 하는지 함께 보여줍니다.

## 구형 주소 호환

초기 점수형 아이디어 랩, 전공 DNA, 구형 홈·탐색·보관함 화면 코드는 제거했습니다. 기존 북마크가 깨지지 않도록 주소 파일만 남겨 최신 화면으로 이동합니다.

- `/mentoring`, `/goal`, `/dna`, `/analyzing`, `/home` → `/`
- `/explore`, `/ideas`, `/ideas/compare`, `/evolution-report`, `/feasibility`, `/passport` → `/research`
- `/saved`, `/profile` → `/portfolio`
- `/paper` → `/paper/reader?mode=bite`

논문 한입 MVP는 공개 초록, 허용된 공개 PDF에서 추출한 텍스트, 또는 사용자가 직접 붙여 넣은 80~12,000자의 범위만 분석합니다. 모든 논문의 본문을 보장하는 기능이 아니라 서비스 공식 서지를 빠짐없이 보여주고 공개 가능한 내용만 선택 시점에 가져오는 구조입니다. 관련 공개 논문을 학생이 확인한 경우 PDF 단계의 `공개 PDF 자동 열기`로 10MB·40쪽 이하 검증본을 현재 브라우저 메모리에서 바로 열 수 있으며, 직접 업로드도 유지합니다. PDF 자동 추출은 `CC BY`, `CC BY-SA`, `CC0/퍼블릭 도메인`처럼 재사용 조건이 명확하고 검증된 학술 저장소에 있는 공개본으로 제한합니다. 라이선스가 없거나 유료·로그인·기관 인증이 필요한 원문은 우회하지 않습니다.

## 기술 구성

- Next.js 15 App Router
- React 19, TypeScript
- Zustand persist 기반 브라우저 로컬 상태
- OpenAI Responses API와 strict JSON Schema 기반 맞춤 결과 생성
- Tailwind CSS 4와 전용 CSS 디자인 시스템
- Lucide 아이콘

분석 시 입력 프로필과 논문에서 추출한 텍스트는 앱의 서버 API를 거쳐 OpenAI Responses API로 전송됩니다. API 키는 서버에서만 읽으며 클라이언트 번들에 포함하지 않습니다. 자동으로 내려받은 PDF 원본은 저장하지 않고 텍스트 추출 뒤 폐기합니다. 생성 결과, 선택 주제, 공식 교수 연결 결과, Knock Kit와 Mentor Loop 수정 내용은 브라우저 `localStorage`에 저장됩니다.

공동설계 AI 호출에 실패하면 준비된 샘플 결과로 흐름을 이어가며, 화면에서 샘플 결과임을 표시합니다. 논문 한입은 오류를 그대로 안내하고 결과를 임의로 생성하지 않습니다. AI가 생성한 탐색 방향은 외부 출처 검증을 마친 최신 동향으로 표시하지 않습니다.

화면 검증용 가상 교수 데이터는 제거했습니다. 공식 데이터 수집 결과는 출처·수집일·공식 프로필 미기재·robots 차단 상태와 함께 관리합니다. 회원 로그인, 여러 기기 동기화, 이메일 자동 발송은 후속 연동 범위입니다.
