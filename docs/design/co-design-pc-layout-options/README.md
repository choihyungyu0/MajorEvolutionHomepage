# AI 공동설계 PC 화면 구성 시안

현재 `/co-design`의 정보와 기능을 유지하고 PC 화면의 구성만 다르게 설계한 비교안이다. 생성 이미지는 배치와 밀도를 논의하기 위한 콘셉트이며, 실제 구현에서는 모든 글자와 컨트롤을 코드로 제작한다.

> 2026-08-23 결정: **C. 대화형 스튜디오**를 PC 최종 구성으로 선택해 `/co-design`에 구현했다. 모바일은 기존 단일 질문 흐름을 유지한다.

## A. 집중형 워크벤치

- 파일: `option-a-focus-workbench.png`
- 구성: 상단 탐색 방식, 왼쪽 8열 질문 패널, 오른쪽 4열 맥락·근거 패널
- 장점: 현재 구조에서 이동 비용이 가장 작고 질문과 다음 행동이 명확하다.
- 주의: 기존 화면과 차이가 가장 작아 발표에서 혁신적으로 보이는 정도는 낮다.
- 추천 상황: 최종 발표 전 안정적으로 완성도를 올릴 때

## B. 단계형 코치

- 파일: `option-b-guided-steps.png`
- 구성: 글로벌 메뉴, 5단계 질문 레일, 중앙 질문 패널, 오른쪽 맥락 패널
- 장점: 현재 위치와 남은 질문이 명확해 이탈과 불안을 줄이기 좋다.
- 주의: 좌측 레일이 추가되어 작은 노트북에서는 중앙 폭이 좁아질 수 있다.
- 추천 상황: 튜토리얼과 공동설계 과정을 하나의 일관된 경험으로 연결할 때

## C. 대화형 스튜디오

- 파일: `option-c-conversation-studio.png`
- 구성: 상단 맥락 요약, 왼쪽 AI 대화·직접 입력, 오른쪽 제안 방향 선택
- 장점: 설문이 아니라 AI와 함께 사고를 발전시키는 서비스라는 정체성이 가장 강하다.
- 주의: 현재 폼 구조에서 변경 범위가 가장 크며, AI 응답 상태와 접근성 설계가 추가로 필요하다.
- 추천 상황: 장기적인 대표 화면 또는 발표용 핵심 데모

## 추천

최종 선택은 C이며, 실제 구현에서는 시안의 가상 `탐색/구체화` 토글을 현재 서비스의 `자유 탐색/AI 트렌드/전공 융합` 방식으로 치환했다. 상단 맥락 요약, 7:5 대화·선택 분할, 직접 입력, 오른쪽 다음 행동이라는 핵심 구성은 그대로 유지했다.
