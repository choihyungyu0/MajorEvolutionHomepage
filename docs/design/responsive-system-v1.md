# 너의 교수님은? 반응형 서비스 기준 v1

## 원칙

- PC와 모바일은 별도 서비스가 아니라 같은 데이터·행동을 공유한다.
- 모바일 화면을 단순 확대하거나 PC 화면을 단순 축소하지 않는다.
- 모바일은 `지금 할 일 → 현재 맥락 → 다음 단계` 순서로 한 열에 배치한다.
- PC는 좌측 서비스 메뉴, 중앙 핵심 작업, 우측 현재 맥락 패널을 사용한다.
- 연락·저장·선택 같은 핵심 기능은 특정 화면 크기에서만 보이도록 숨기지 않는다.

## 화면 구간

| 구간 | 기준 | 구조 |
| --- | --- | --- |
| Mobile | 0–767px | 상단 브랜드 + 한 열 본문 + 하단 6탭 |
| Tablet / small PC | 768–1279px | 하단 6탭 + 넓은 한 열 또는 안전한 2열 |
| Desktop | 1280px 이상 | 좌측 메뉴 + 중앙 작업 + 292–320px 맥락 패널 |

PC 좌측 메뉴와 맥락 패널은 실제 본문 폭이 충분한 1280px부터 사용한다. 1024px 전후에서는 하단 메뉴를 유지하고 세 칼럼을 강제하지 않는다.

## 화면별 우선순위

- 홈: 다음 행동 → 선택 교수 → 준비 진행률 → AI 대화 지도 → 최근 기록
- 교수 매칭: 매칭 시작 → 선택 교수 → 저장 교수 → 공식 정보 상태
- 교수 만남 준비: 현재 할 일 → 연결 교수 → 첫 만남 단계 → 단계별 도구
- 프로젝트: 프로젝트 설계 → 현재 프로젝트 → 생성 근거 → 다음 질문
- 맞춤 교수 추천: 추천 확인 → 선택 프로젝트 → 교수 역할 → 연결 근거
- 성장: AI 교수님 → 다음 기록 → 변화 흐름 → 전체 기록
