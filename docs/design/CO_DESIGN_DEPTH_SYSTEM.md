# AI 공동설계 화면 명암·상태 시스템

## 목표

공동설계 화면의 정보 구조와 질문 순서는 유지하면서, 실제 서비스처럼 사용자가 지금 집중할 곳과 보조 정보를 즉시 구분하도록 만든다.

## 참고한 공식 디자인 원칙

- Toss TDS: 흰색 기본 배경과 `grey50`·`grey100` 계열의 보조 배경을 분리하고, 컴포넌트 상태에 따라 표면색을 사용한다.
- Atlassian Design System: 기본·눌린(sunken)·올라온(raised) 표면을 역할에 따라 나누며, 모든 카드에 강한 그림자를 쓰지 않는다.
- Material Design 3: elevation은 장식이 아니라 겹침과 집중 순서를 전달하는 수단으로 사용한다.

## 적용 규칙

1. 화면 바탕은 연한 회색으로 낮춘다.
2. 사용자가 현재 답하는 질문 패널만 흰색·경계·부드러운 그림자로 올린다.
3. 지금까지 확인한 맥락은 회색 보조 표면으로 눌러 질문보다 한 단계 낮춘다.
4. 선택된 탐색 방식은 색 테두리, 옅은 색면, `선택됨` 상태 라벨로 세 가지 단서를 제공한다.
5. 답변 버튼은 기본·호버·선택 상태의 명암을 다르게 한다.
6. 질문 이동 버튼은 패널 하단의 별도 행동 영역으로 묶는다.
7. 데스크톱에서는 맥락 패널을 고정해 긴 질문 흐름에서도 현재 맥락을 잃지 않게 한다.

## 화면 토큰

- Canvas: `#f5f7fb`
- Raised surface: `#ffffff`
- Sunken surface: `#f8fafc`
- Subtle border: `#e4e9f2`
- Raised shadow: 낮은 2단 그림자
- Selected shadow: 파란색 계열의 제한된 강조 그림자

## 확장 기준

이 규칙은 `/result`, `/project-professors`, `/portfolio`에도 동일하게 적용할 수 있다. 다만 각 화면에서 가장 중요한 행동 패널 하나만 `raised`로 올리고, 정보 카드 전부를 동시에 띄우지 않는다.
