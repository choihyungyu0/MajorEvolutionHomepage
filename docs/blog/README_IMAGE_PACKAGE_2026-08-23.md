# 너의 교수님은? 최종 블로그 이미지 패키지

이 패키지는 네이버 블로그 최종 글에 바로 사용할 수 있도록 구성했습니다.

## 폴더 구성

- `images/`: 실제 서비스 화면 8장과 블로그용 도식 10장
- `FINAL_DEVELOPMENT_BLOG_2026-08-23.md`: 이미지가 배치된 최종 원고
- `BLOG_IMAGE_UPLOAD_GUIDE_2026-08-23.md`: 네이버 블로그 업로드 순서
- `BLOG_VISUAL_PACKAGE_2026-08-23.md`: 이미지별 크기·용도·근거
- `visual-source/`: 09~18번 도식을 다시 수정할 수 있는 HTML·CSS 원본과 초기안 참고 이미지

## 바로 쓰는 방법

1. `FINAL_DEVELOPMENT_BLOG_2026-08-23.md`를 열어 본문을 복사합니다.
2. `BLOG_IMAGE_UPLOAD_GUIDE_2026-08-23.md`의 순서대로 `images/`의 파일을 올립니다.
3. 대표 이미지는 `09-blog-cover.png`를 사용합니다.
4. 게시 전 교수·논문 정보가 현재 서비스 데이터와 같은지만 마지막으로 확인합니다.

## 이미지 수

- 실제 서비스 화면: 01~08, 총 8장
- 블로그 설명용 비주얼: 09~18, 총 10장
- 전체: 18장
