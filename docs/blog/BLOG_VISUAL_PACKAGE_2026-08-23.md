## 제작 근거

- 실제 화면: `localhost:3000`에서 구현 상태를 직접 렌더링해 캡처
- 초기안 비교: 팀이 제공한 초기 12개 모바일 화면 시안 사용
- 제품 성장 과정: `docs/presentations/FINAL_GROWTH_STORY_2026-08-20.md`의 버전 기록 사용
- 브랜드: 현재 프로젝트의 네이비·바이올렛·민트 토큰과 공식 로고·캐릭터 자산 사용
- 외부 스톡 이미지: 사용하지 않음

## 사용 권리와 주의사항

- 서비스 화면과 브랜드 자산은 팀 프로젝트 내부 자산입니다.
- 초기안 이미지는 팀이 제공한 자료를 사용했습니다.
- 교수 이름·논문·프로필처럼 실제 정보가 포함된 화면은 공개 게시 전 최종 데이터 상태를 한 번 더 확인합니다.
- API 키, 환경변수, 개인 연락처는 어떤 이미지에도 노출하지 않았습니다.
