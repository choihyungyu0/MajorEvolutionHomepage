브라우저 콘솔 오류는 없었다. 모바일 390×844에서 공통 3문항 답변 뒤 앞선 맥락을 반영한 맞춤 질문 2문항이 생성되고, 새 질문 제목이 고정 헤더 아래 72px 지점에 놓이는 것을 확인했다. 아이디어 후보를 선택한 뒤 프로젝트 멘토 교수 3명이 공식 후보 안에서 서로 다른 역할로 표시되는 흐름을 모바일과 데스크톱 1440×900에서 확인했다. 새 내비게이션은 모바일에서 다섯 탭이 75px씩 같은 폭으로 보이며 `교수 매칭 → 교수 만남 연계 → AI 프로젝트 설계 → 맞춤 교수 추천`을 순서대로 이동했다. 맞춤 교수 추천 허브는 프로젝트 없음과 추천 완료 상태에서 각각 설계 시작과 추천 근거 CTA를 노출했다. 첫 교수 피칭은 프로덕션 빌드에서 같은 학과·주제·방법 순서, 모바일 가로 스냅, 카드 상세 접기, 교수 선택 뒤 `/quest`에서 선택 교수의 논문 준비를 제시하는 흐름을 확인했다.
