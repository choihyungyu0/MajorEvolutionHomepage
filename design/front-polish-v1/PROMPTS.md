# Built-in ImageGen Prompt Set

모든 이미지는 Built-in ImageGen 모드로 만들었다.

## 데스크톱 UI 시안

현재 1440×900 튜토리얼 스크린샷을 정보구조 참조로 사용했다. `너의 교수님은?`의 문구와 흐름을 유지하면서 true-white academic editorial product UI, 12-column grid, 의도적인 60/40 분할, 8px 간격계, 10~12px 반경, deep navy/mint/violet 역할 분리, 한 개의 주 CTA를 요구했다. 보라-파랑 그라데이션, glassmorphism, 카드 그리드, 동일 패딩 반복, 이모지, 로봇 중심 장식, 가짜 지표와 새 섹션을 금지했다.

## 모바일 UI 시안

현재 390×844 첫 화면을 참조로 사용했다. 16px 여백, 56px 헤더, 8px 간격계, 30~32px 제목, 15px 본문, 16:9 장면, 48~52px 열린 약속 행, 단색 보라 CTA와 직접 연결된 개인정보 안내를 요구했다. 필수 문구와 CTA가 한 네이티브 뷰포트에 보이도록 하고, 그라데이션·글로우·pill 칩·로봇·중첩 카드·비대칭 아이콘 가족을 금지했다.

## 튜토리얼 장면 편집

`nyp-scene-tutorial-first-path-16x9-v01.webp`를 편집 대상으로 사용했다. 작은 흰 로봇과 cyan-purple 발광 경로만 제거하고 보도블록을 자연스럽게 복원하도록 요청했다. 학생의 정체성·자세·옷·크기·위치·표정·조명과 캠퍼스·나무·하늘·카메라 각도·16:9 구도를 모두 유지하고, 새 인물·새 물체·텍스트·로고·워터마크·AI 상징을 금지했다.
