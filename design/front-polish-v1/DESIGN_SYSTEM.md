# Front Polish V1 디자인 시스템

## 한 문장 방향

`대학생이 고민을 정리해 첫 대화를 준비하는 차분한 학업 도구` — AI 기술을 장식으로 과시하지 않고, 학생의 다음 행동과 공식 정보의 신뢰를 먼저 보여준다.

## 토큰

| 축 | 값 | 용도 |
|---|---|---|
| 배경 | `#FFFFFF` | 앱과 튜토리얼의 기본 화면 |
| 본문 | `--brand-navy-950` | 제목과 중요한 정보 |
| 보조 글자 | `--text-secondary` | 설명과 메타 정보 |
| 주 행동 | `--brand-purple` | CTA와 선택 상태만 |
| 신뢰 | `--brand-mint-dark` | 공식 정보·보호 안내 |
| 간격 | `4, 8, 12, 16, 24, 32, 48px` | 8px 기본, 4px 보조 |
| 반경 | `8, 12, 16px` | 작은 제어·기본 제어/미디어·큰 표면 |
| 제어 높이 | `52px` | 주 버튼, 모바일 최소 터치 영역 48px 이상 |
| 그림자 | 기본 없음 | 모달처럼 실제로 떠 있는 상태만 제한적으로 사용 |

## 타이포

- 데스크톱 H1: 44~48px, 1.16~1.2 행간
- 모바일 H1: 29~30px, 약 1.22 행간
- 본문: 15~16px, 1.6 행간
- 행·버튼: 13~15px, 700~800
- 한 화면에서 본문보다 큰 크기는 최대 세 단계까지만 사용한다.

## 레이아웃

- 데스크톱 튜토리얼: 맥락과 질문을 두 열로 나누되, 첫 진입은 학생 맥락 54% / 행동 46% 정도로 배분한다.
- 모바일: 16px 좌우 여백, 56px 헤더, 진행 상태 → `이미지+제목+설명` 시작 장면 → 약속 목록 → 전체 너비 CTA 순서다.
- 시작 장면은 이미지 하단에 두 방향의 어두운 그라데이션을 겹쳐 글자 대비를 보장한다. 일반 질문 단계의 이미지는 16:9를 유지한다.
- 상세 기능은 동일 패딩 카드 여러 개보다 열린 행 목록을 우선한다.
- 주 행동이 하나일 때만 보라색 면을 사용한다.

## 미디어

- 일반 튜토리얼 장면 비율: 16:9. 모바일 시작 장면은 320~390px 제한 높이의 배경형 미디어다.
- 원본은 1672×941 PNG이며 Next Image가 화면별 크기로 최적화한다.
- 장면은 가상 학생·가상 캠퍼스 이미지다. 실제 인물이나 특정 대학의 공식 사진이 아니다.
- 대체 텍스트: `캠퍼스에서 자신의 고민을 정리하며 교수와의 첫 대화를 준비하는 학생`.

## 상태

- 기본: 흰 배경, 단색 CTA, 얇은 구분선.
- 선택: 보라색 선과 아주 옅은 배경. 그림자를 추가하지 않는다.
- 신뢰: 민트 아이콘 + 설명 문구를 함께 제공한다.
- 비활성: 회색 면과 명시적 비활성 문구/상태를 유지한다.
- 오류: 색만 쓰지 않고 오류 문구를 같이 보여준다.
