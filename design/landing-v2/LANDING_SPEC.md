# 너의 교수님은? 공개 랜딩 v2 구현 기준

## 목적

처음 방문한 대학생이 첫 화면에서 서비스의 가치를 이해하고, 아래 내용을 순서대로 납득한 뒤 `3분 방향 찾기`를 시작하게 한다.

1. 이 서비스가 누구를 위한 것인지
2. 어떤 문제를 해결하는지
3. AI와 교수는 각각 어떤 역할을 하는지
4. 실제로 무엇을 해볼 수 있는지
5. 정보와 연락을 어떻게 안전하게 다루는지

기존 통합 홈은 서비스에 진입한 사용자의 제품 홈이므로 `/home`으로 분리한다.

## 한 문장 정의

> 대학생의 막연한 전공·진로 고민을 정리하고, 학교 공식 정보로 지금 대화해 볼 교수를 찾고, 첫 질문과 다음 행동까지 준비하는 서비스.

## 첫 화면 카피 잠금

- 브랜드: `너의 교수님은?`
- 내비게이션: `서비스 소개`, `해결 방식`, `이용 흐름`, `신뢰 원칙`
- 로그인/복귀: `이어하기`
- H1: `막막한 전공·진로 고민, 이제 누구와 이야기할지부터 찾으세요.`
- 본문: `고민을 정리하고, 학교 공식 정보로 교수를 찾고, 첫 질문과 다음 행동까지 준비합니다.`
- 주 CTA: `3분 방향 찾기`
- 보조 CTA: `서비스 흐름 보기`
- 신뢰 문구: `학교 공식 정보 기반 · 교수에게 자동으로 연락하지 않아요`

## 섹션 순서

1. **Hero** — 서비스 케치프라이즈, 핵심 가치, 시작 CTA, 캠퍼스 여정 장면
2. **Problem** — 정보 부족이 아니라 대화를 시작하는 과정이 흩어져 있다는 문제
3. **Promise** — 검색이 아니라 대화를 시작하는 과정을 설계했다는 해결 관점
4. **How it works** — 고민 정리 → 근거로 교수 찾기 → 첫 대화와 다음 행동 잇기
5. **Experience** — 교수 연결 이유, 논문 한입, 첫 질문·이메일, 면담 후 7일 행동
6. **Trust** — 공식 출처와 확인일, 확인/질문 분리, 연락은 학생이 직접
7. **Audience** — 진로·수업·프로젝트·연구/대학원 중 어디서든 시작 가능
8. **Closing CTA** — 가입 없이 3분 방향 찾기, 이어하기
9. **Footer** — 서비스 설명, 주요 링크, 정책 링크

## 반응형 기준

- 1440px: 최대 콘텐츠 폭 1240px, 히어로 2열, 서비스 흐름은 교차 편집형
- 1024px: 히어로 52/48 유지, 본문 간격 축소
- 768px 이하: 내비게이션 메뉴 숨김, 히어로 단일 열, 이미지가 카피 아래로 이동
- 390px: 주 CTA 전폭, H1 최대 4줄, 문제 항목과 결과 항목은 세로 목록
- 모바일에서도 `Hero → Problem`의 다음 섹션 단서가 첫 스크롤 안에 보이게 한다.

## 컴포넌트

| 컴포넌트 | 목적 | 상태/접근성 |
|---|---|---|
| LandingHeader | 공개 페이지 이동과 시작 | sticky, 키보드 포커스, 모바일 메뉴 |
| HeroActions | 첫 시작과 흐름 앵커 | 주/보조 버튼, 44px 이상 |
| ProblemList | 문제 공감 | 아이콘은 장식, 텍스트가 의미 전달 |
| JourneyStep | 3개 해결 흐름 | 숫자+제목+설명+이미지 대체 텍스트 |
| OutcomeRail | 실제 만들 수 있는 결과 | 작은 화면은 세로 목록, 순서 유지 |
| TrustPrinciple | AI 책임 경계 | 색뿐 아니라 제목·설명으로 구분 |
| ClosingCTA | 전환 | 시작과 이어하기를 명확히 분리 |

## 시각 규칙

- 배경은 순백색을 기본으로 하고 연한 라벤더 구간과 네이비 신뢰 구간만 사용한다.
- 네이비 `#071026`, 바이올렛 `#7557F6`, 민트 `#31C9AE`를 고정한다.
- 카드 그리드를 반복하지 않고 열린 문단, 넓은 미디어 프레임, 연결선, 밴드로 리듬을 만든다.
- 히어로 이미지는 색상 오버레이 없이 오른쪽에서 자연스럽게 흰 배경으로 페이드한다.
- 교수 궁합 점수, 순위, 성공 확률, 가짜 지표, 가짜 후기를 만들지 않는다.
- 실제 UI 텍스트·버튼·링크는 모두 코드로 구현한다.

## 상호작용

- `3분 방향 찾기` → `/tutorial`
- `서비스 흐름 보기` → `#flow`
- `이어하기` → `/home`
- 헤더 내비게이션 → 각 섹션 앵커
- 스크롤 등장 효과는 한 번만 실행하고 `prefers-reduced-motion`에서 제거한다.

## 완료 조건

- PC와 모바일에서 동일한 핵심 메시지와 CTA를 이해할 수 있다.
- 랜딩과 로그인 후 제품 홈이 명확히 분리된다.
- 첫 화면에서 서비스 대상, 문제, 해결 결과, CTA가 보인다.
- 이미지 없이도 서비스 흐름과 신뢰 기준을 이해할 수 있다.
- 이미지가 텍스트나 CTA를 가리지 않는다.
- 타입 검사, 프로덕션 빌드, 콘솔, 링크, 모바일 오버플로 검증을 통과한다.
