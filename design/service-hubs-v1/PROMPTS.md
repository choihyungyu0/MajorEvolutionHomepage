# ImageGen prompt set

Mode: built-in ImageGen

## Professor hub desktop

`ui-mockup`으로 1440×900 전체 데스크톱 앱 화면을 요청했다. 토스의 쉬운 질문·주 행동 하나, 당근의 생활 언어·단순한 목록 구조를 구조 레퍼런스로 사용하되 상표·색·화면을 복제하지 않도록 제한했다. 코드 네이티브 문구는 `누구와 이야기할지 찾아볼까요?`, `3분 교수 찾기`, `지난 교수 연결 보기`, `내 교수 연결`, `저장한 교수`로 고정했다. 흰 배경·딥 네이비·바이올렛·민트, 좌측 내비게이션, 한 개의 넓은 주 행동 영역, 두 개의 목록 행을 요청했다. 긴 배너·폼·필터 칩·카드 그리드·가짜 수치·3D·그래디언트는 금지했다.

## Quest hub mobile

`ui-mockup`으로 390×844 전체 모바일 앱 화면을 요청했다. 첫 화면에는 `지금은 첫 질문을 준비할 차례예요`, `첫 질문 3개 준비하기`, `질문 준비하기`와 `만나기 전·대화 중·만난 후` 세 행, `홈·교수·아이디어·준비·기록` 고정 하단 메뉴만 배치했다. 단일 주 행동 영역 외에는 열린 목록과 구분선을 사용하고, 44px 이상 터치 영역을 요청했다. 장면 배너·필터 칩·Q 코드·카드 그리드·긴 설명·AI 대시보드 표현은 금지했다.

## Portfolio hub desktop

`ui-mockup`으로 1440×900 전체 데스크톱 앱 화면을 요청했다. `준비하며 달라진 과정을 모았어요`, 다음 행동 띠, `나의 성장 기록`, 완료 2행과 다음 빈 기록 1행, `포트폴리오 만들기`, `내 기록 관리`만 한 화면에 배치했다. 기존 3열 편집기·전체 미리보기·삭제 제어는 전용 화면으로 분리하도록 요청했다. 흰 배경·딥 네이비·바이올렛·민트와 열린 타임라인 목록을 사용하고 카드 그리드·가짜 지표·장식 이미지는 금지했다.
