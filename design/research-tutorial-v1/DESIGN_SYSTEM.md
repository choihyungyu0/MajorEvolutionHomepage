# 전공 아이디어 튜토리얼 디자인 시스템

## 방향

기존 너의 교수님은?의 차분한 학업 서비스 무드를 유지한다. 생성형 AI를 연상시키는 로봇·유리 효과·네온 장식 대신, 분명한 타이포그래피와 선택 상태로 다음 행동을 설명한다.

## 토큰

| 역할 | 값 |
| --- | --- |
| 배경 | #FFFFFF |
| 본문 | #0B1734 |
| 보조 본문 | #59657D |
| 주 행동 | #5B35E8 |
| 선택 배경 | #F4F1FF |
| 신뢰 | #0D9F91 |
| 신뢰 배경 | #EEFAF8 |
| 경계 | #DBE1EB |
| 제어 반경 | 13~17px |
| 화면 전환 | 260ms, reduced-motion 시 제거 |

## 레이아웃

- PC: 질문 영역과 좁은 확인 레일의 2열. 하단 행동은 화면 아래 고정.
- 모바일: 질문 단일 열. 확인 레일은 제거하고 마지막 확인 화면에서 전체 조건을 다시 보여준다.
- 카드 그리드 대신 열린 선택 목록, 구분선, 하나의 주 행동을 사용한다.

## 구성요소

- 진행 레일: 질문 단계와 남은 범위를 텍스트로 함께 전달.
- 선택 행: 기본·호버·포커스·선택 상태를 가짐.
- 다중 선택: 최대 개수를 텍스트로 표시하고 선택 해제가 가능함.
- 조건 레일: 이미 확인한 사용자 입력만 표시.
- 최종 확인 행: 값과 수정 행동을 같은 행에 배치.
- 하단 행동: 이전은 보조, 다음·공동설계는 주 행동.

## 접근성

- 선택 상태는 색뿐 아니라 체크와 aria-pressed 또는 aria-checked로 전달한다.
- 키보드 포커스는 3px 외곽선으로 표시한다.
- 오류는 해당 단계 하단의 role=alert로 읽힌다.
- 모바일 터치 영역은 최소 46px 이상이다.
