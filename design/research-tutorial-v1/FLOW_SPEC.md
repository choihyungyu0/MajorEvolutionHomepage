# 전공 아이디어 튜토리얼 흐름

기준일: 2026-08-23

## 목적

전공 아이디어 기능을 처음 여는 학생이 긴 조건 폼에서 순서를 판단하지 않아도, 한 번에 한 맥락씩 답하고 기존 공동설계 흐름으로 자연스럽게 들어가게 한다.

## 핵심 흐름

1. 시작 안내
2. 학교·전공
3. 탐색 방식
4. 관심 분야
5. 관련 경험·가능한 방법
6. 기간·자료 접근
7. 최종 확인
8. 공동설계

질문 단계는 화면 진행률에서 6단계로 계산한다. 시작 안내는 질문 수에 포함하지 않는다.

## 화면 계약

| 상태 | 목적 | 주 행동 | 보조 행동 | 다음 상태 |
| --- | --- | --- | --- | --- |
| 시작 | 기능 가치와 부담 설명 | 전공 아이디어 시작 | 기존 아이디어 이어보기, 한 번에 입력 | 전공 |
| 전공 | 현재 학업 맥락 확인 | 다음 질문 | 이전 | 탐색 방식 |
| 탐색 방식 | 전공 안·AI 접목·전공 융합 중 선택 | 다음 질문 | 이전 | 관심 |
| 관심 | 관심 분야 1~3개 확인 | 다음 질문 | 직접 입력, 이전 | 경험·방법 |
| 경험·방법 | 현재 실행 가능한 수준 확인 | 다음 질문 | 이전 | 기간·자료 |
| 기간·자료 | 현실적인 범위 확인 | 다음 질문 | 이전 | 최종 확인 |
| 최종 확인 | 저장 전 조건 검토 | 공동설계 시작 | 각 항목 수정, 이전 | 공동설계 |

## 데이터 경계

- 질문 중 선택은 major-evolution-research-tutorial-v1 로컬 초안에만 저장한다.
- 최종 확인 전에는 연구 저장소의 교수 후보·선택 교수·성장 기록을 변경하지 않는다.
- 공동설계 시작에서 필수값을 다시 검증한 뒤 조건을 한 번에 반영한다.
- AI 결과는 정답·순위가 아니라 비교 가능한 후보와 추가 확인 항목이다.
- 한 화면 입력을 선호하는 사용자는 기존 /research로 이동할 수 있다.

## 예외·복구

- 새로고침: 마지막 단계와 입력 복원.
- 필수 입력 누락: 해당 단계에서 구체적인 오류 문구 표시.
- 손상된 로컬 초안: 유효한 필드만 복원하고 나머지는 비움.
- 공동설계 직접 진입 실패: /research/tutorial로 복귀.
- 기존 후보가 있음: 시작 화면에서 /result 이어보기 제공.
