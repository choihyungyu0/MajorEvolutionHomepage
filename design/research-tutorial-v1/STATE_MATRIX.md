# 상태 매트릭스

| 상태 | 화면 표현 | 사용자 행동 | 시스템 처리 |
| --- | --- | --- | --- |
| 최초 진입 | 시작 약속 3개, 시작 CTA | 시작 | 새 로컬 초안 생성 |
| 기존 초안 | 마지막 질문 단계와 입력 | 이어서 답변 | 로컬 초안 복원 |
| 기존 결과 | 기존 아이디어 이어보기 | 결과 열기 | /result 이동 |
| 선택 전 | 중립 경계, 다음 버튼 | 항목 선택 | 로컬 초안만 변경 |
| 선택 완료 | 보라 경계·체크·확인 레일 | 다음 질문 | 단계 진행 |
| 최대 선택 | 선택한 값 유지 | 기존 값 해제 후 교체 | 초과 선택 무시 |
| 필수 누락 | 구체 오류 문구 | 누락값 입력 | 같은 단계 유지 |
| 최종 확인 | 조건 6행·수정·신뢰 안내 | 공동설계 시작 | 연구 저장소에 원자적 반영 |
| 저장 복원 중 | 로딩 아이콘·문구 | 대기 | Zustand 재수화 후 렌더 |
| 모바일 | 단일 열·고정 하단 CTA | 같은 과업 완료 | PC와 동일 계약 |
