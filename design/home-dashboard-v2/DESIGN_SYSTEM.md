# 홈 대시보드 UI 시스템

## 시각 방향

- 배경: 순백색 `#FFFFFF`
- 본문 텍스트: 네이비 `#071026`, 보조 텍스트 `#65708A`
- 주 행동: 바이올렛 `#6548DF`
- 완료·공식 확인: 민트 `#168B78`
- 경계: 쿨 그레이 `#DFE4EF`
- 카드 그림자는 주 행동 버튼 외에는 최소화한다.

## 정보 우선순위

1. 사용자의 현재 상태를 설명하는 제목
2. 오늘의 다음 행동 한 개
3. 현재 연결한 교수
4. 첫 대화 준비 진행 레일
5. 실제 저장 기록
6. 전체 기능 링크

## 컴포넌트

| 이름 | 목적 | 상태 | 모바일 |
| --- | --- | --- | --- |
| `NextAction` | 지금 할 일 하나를 크게 제안 | 7단계 문구·링크 변형 | 아이콘·문구·전체 폭 CTA |
| `ProfessorPanel` | 선택 교수와 공식 확인 상태 표시 | 선택·미선택 | 세로 배치, 행동 버튼 한 열 |
| `ProgressRail` | 교수 선택부터 면담 기록까지 연결 | 완료·현재·예정 | 가로 스크롤, 5단계 유지 |
| `RecentRecordRow` | 실제 저장 결과 복귀 | 최대 2개·빈 상태 | 한 줄 말줄임 |
| `UtilityList` | 비선형 보조 진입 | 교수·아이디어·퀘스트 | 리스트형, 카드 그리드 금지 |
| `HomeBottomNav` | 모바일 주요 목적 이동 | 홈 선택 | 화면 하단 고정 |

## 접근성·반응형

- 모든 행동은 링크의 목적을 텍스트로 이해할 수 있다.
- 완료·현재 상태는 색뿐 아니라 `완료`, `진행 중`, `예정` 문구로 구분한다.
- 진행 레일은 좁은 화면에서 잘리지 않고 가로 스크롤한다.
- 390px에서 기본 CTA는 한 손으로 누를 수 있는 전체 폭 52px 높이다.
- `prefers-reduced-motion`에서 버튼 이동 효과를 제거한다.
