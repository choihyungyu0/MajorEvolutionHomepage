# 튜토리얼 UX 흐름 v2

## 핵심 시나리오

1. **안심시키기** — 가입 없이 시작하고 교수에게 자동 연락하지 않는다는 경계를 먼저 알린다.
2. **기본 고민 수집** — 학교·전공, 현재 단계, 원하는 도움, 관심 분야, 현재 고민을 한 질문씩 수집한다.
3. **첫 결과 선택권** — 다섯 질문 뒤 바로 첫 매칭을 보거나 2분 심층 질문으로 더 구체화할 수 있게 한다.
4. **심층 맥락 수집** — 진로 맥락, 원하는 지원 방식, 실제 대화 상황, 자유 서술을 선택적으로 받는다.
5. **사용자 확인** — 입력 내용을 한 화면에서 검토하게 한 뒤에만 첫 매칭을 시작한다.
6. **근거 기반 연결** — 고민을 정리하고 학교 공식 정보를 대조한 뒤 연결 이유와 첫 질문을 보여준다.

## 길을 잃지 않게 하는 장치

- 한 화면에 질문 하나만 보여준다.
- `기본 질문 n/5`, `심층 질문 n/3`으로 현재 위치를 항상 표시한다.
- 브라우저 임시 저장과 `처음부터`를 헤더에 고정한다.
- 필수 답변 전에는 다음 버튼을 비활성화한다.
- 이전 버튼으로 언제든 수정할 수 있다.
- 심층 질문은 건너뛸 수 있고, 매칭 전 검토 화면을 반드시 거친다.

## 전환 문구

- 시작: `내 고민부터 시작하기`
- 기본 완료: `이 정보로 첫 매칭 보기` / `2분 더 알려주기`
- 최종 확인: `첫 매칭 시작`
- 신뢰 경계: `최종 연락과 선택은 학생이 직접 진행합니다.`

## 성공 조건

- 처음 온 사용자가 5초 안에 서비스가 묻는 내용과 소요 시간을 이해한다.
- 기본 경로는 3분 안에 완료할 수 있다.
- 사용자는 추천이 교수 순위가 아니라 대화 연결이라는 점을 이해한다.
- 사용자는 언제 AI 정리가 쓰이고, 어떤 정보가 공식 출처인지 구분할 수 있다.
