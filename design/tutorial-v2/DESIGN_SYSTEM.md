# 튜토리얼 UI 시스템 v2

## 디자인 의도

튜토리얼은 AI 기능을 과시하는 화면이 아니라, 대학생이 자기 고민을 부담 없이 정리하고 교수와의 첫 대화를 준비하는 화면이다. 따라서 장식보다 질문의 순서, 선택 상태, 공식 정보의 근거를 먼저 보이게 한다.

## 토큰

| 역할 | 값 | 사용 |
| --- | --- | --- |
| Navy | `#071026` | 제목, 핵심 텍스트 |
| Violet | `#7557F6` | 진행 상태, 주 행동, 선택 상태 |
| Mint | `#31C9AE` / `#168B78` | 신뢰, 확인, 보조 강조 |
| Surface | `#FFFFFF` | 기본 화면 |
| Soft surface | `#F7F7FB` | 구획 배경, 비활성 상태 |
| Border | `#DFE3E9` | 입력, 카드, 구분선 |
| Muted | `#657086` | 설명, 보조 정보 |

## 레이아웃

- 데스크톱: 맥락 46% / 입력 54%의 2열 구조. 왼쪽에는 질문의 이유와 현재 단계를, 오른쪽에는 이번 단계에서 할 행동만 둔다.
- 모바일: 진행률 → 질문 → 보조 이미지 → 입력 → 이전/다음 순서의 단일 열이다.
- 화면마다 주 행동은 하나만 강하게 표현한다.
- 이미지는 UI 카드 안의 설명 보조물이며 텍스트나 입력 위에 겹치지 않는다.

## 컴포넌트 규칙

- `BrandLogo`: 생성형 심벌과 코드 기반 한글 워드마크를 결합한다. 워드마크는 이미지로 굽지 않아 모든 크기에서 선명하다.
- `Progress`: 연회색 선 위에 단색 보라 진행 상태를 사용한다.
- `Choice`: 기본은 흰색+회색 테두리, 선택 시 연보라 배경+보라 테두리로만 상태를 표현한다.
- `PrimaryButton`: 단색 보라, 52px 높이, 최소 그림자. 그라데이션과 네온 효과를 쓰지 않는다.
- `TrustNote`: 민트 아이콘과 짧은 문장으로 공식 데이터 범위와 사용자 통제권을 알린다.
- `FormField`: 라벨을 입력 위에 고정하고, 포커스는 보라색 3px 링으로 표시한다.

## 피해야 할 표현

- 로봇 캐릭터의 반복 노출
- AI 반짝임, 홀로그램, 과도한 글로우
- 보라색 전체 패널, 유리 질감, 많은 카드가 떠 있는 대시보드형 화면
- 점수, 순위, 과장된 추천 확률처럼 현재 서비스 의도에서 제외한 표현

## 접근성

- 모든 조작 영역은 최소 44px 이상이다.
- 선택은 색상뿐 아니라 체크 아이콘과 `aria-pressed`로 함께 전달한다.
- 모바일 입력 화면에서 하단 버튼이 필드를 가리지 않도록 문서 흐름에 배치한다.
- `prefers-reduced-motion`에서는 진행 애니메이션을 제거한다.
