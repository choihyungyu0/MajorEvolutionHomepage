# 튜토리얼 v2 시안 대조표

비교 기준:

- 데스크톱 시안: `concepts/tutorial-desktop-1440x900-v01.png`
- 데스크톱 구현: `verification/tutorial-desktop-academic-v01.jpg`
- 모바일 시안: `concepts/tutorial-mobile-390x844-v01.png`
- 모바일 구현: `verification/tutorial-mobile-implementation-v01.png`

| 비교 항목 | 시안 의도 | 구현 결과 | 판정 |
| --- | --- | --- | --- |
| 1. 전체 구조 | 데스크톱 2열, 모바일 1열 | 1040px 이상 2열, 760px 이하 1열 전환 | 일치 |
| 2. 정보 위계 | 진행률 → 질문 → 설명 → 이미지/입력 | 같은 순서로 배치하고 제목을 가장 강하게 처리 | 일치 |
| 3. 색과 질감 | 흰색, 네이비, 제한된 보라·민트 | 전체 보라 패널과 과한 글로우를 제거하고 단색 버튼 사용 | 일치 |
| 4. 입력 UI | 열린 폼, 얇은 테두리, 실제 라벨 | 학교 공식 정보, 단과대, 주전공 필드로 구현 | 일치 |
| 5. 이미지 역할 | 질문을 보조하며 본문과 겹치지 않음 | 별도 figure로 배치, 16:9 비율 유지 | 일치 |
| 6. 로고 | 두 인물 연결 심벌+한글 워드마크 | 생성형 심벌+코드 타이포로 구현 | 의도 유지, 심벌은 브랜드 개성 강화 |
| 7. 하단 행동 | 이전/다음의 명확한 우선순위 | 주 버튼은 보라, 이전은 테두리 버튼 | 일치 |
| 8. 모바일 가림 방지 | 입력 뒤 행동 버튼 | 고정 오버레이를 제거해 주전공 입력을 가리지 않음 | 보완 완료 |
| 9. 서비스 경계 | 자동 연락 없음, 공식 정보 범위 표시 | 헤더·학교 필드·하단 안내에서 반복 확인 | 일치 |

## 의도적으로 다른 부분

- 시안은 학교를 드롭다운처럼 보이게 했지만 구현은 파일럿 범위를 정확히 알리기 위해 `단국대학교`를 읽기 전용 공식 정보 필드로 유지했다.
- 시안의 로고는 추상 벡터였으나, 사용자의 생성형 공식 로고 요청을 반영해 생성형 심벌을 사용하고 워드마크만 코드로 유지했다.
